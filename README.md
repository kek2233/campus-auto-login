# 校园网自动连接

新疆联通校园宽带（Panabit 门户）自动认证工具，支持开机自启、掉线自动重连、验证码自动识别。

## 功能

- 🚀 **一键认证**：自动识别验证码，无需手动输入
- 🔄 **掉线自动重连**：后台监控，断网立即重连
- 🔐 **记住密码**：账号密码本地保存，下次自动登录
- 📊 **图形界面**：浅色标签页风格，操作简单
- ⚡ **开机自启**：开机自动运行，无需手动操作

## 使用方法

1. 双击 `校园网自动连接.exe` 启动
2. 在顶部输入手机号和校园网密码
3. 点击"登录"按钮
4. 勾选"记住密码"，下次自动填充
5. 在"设置"页可以开启开机自启

## 技术栈

- Python 3.x
- tkinter（GUI）
- pycryptodome（DES 加密）
- ddddocr（验证码识别）
- PyInstaller（打包）

## 项目结构

```
校园网自动连接/

├── config.json     # 配置文件
├── 校园网自动连接.exe  # 打包好的程序

```

## 说明

- 仅支持新疆联通校园宽带（Panabit 网关）
- 验证码识别基于 ddddocr，识别准确率 95%+
- 账号密码仅保存在本地，不会上传
